# 🎓 Mood Learning System

Mood Learning System adalah aplikasi web berbasis Laravel yang membantu siswa belajar sesuai dengan kondisi mood mereka. Sistem ini memberikan rekomendasi materi pembelajaran berdasarkan mood yang dipilih oleh pengguna.

---

## 🚀 Fitur Utama

- 🔐 Login & Register
- 😊 Mood Check (Semangat, Biasa, Lelah, Bingung)
- 📚 Rekomendasi Materi Otomatis
- 📝 Quiz Pembelajaran
- 📊 Dashboard Analisis
- 📜 History Pembelajaran
- 👤 Profile Pengguna

---

## 🧠 Alur Sistem

1. Login ke sistem
2. Memilih mood belajar
3. Sistem memberikan materi sesuai mood
4. Mengerjakan quiz
5. Data disimpan ke sistem
6. Hasil ditampilkan di dashboard
